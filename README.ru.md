# CD

**Независимое ревью кода и ограниченный цикл исправлений для Codex.**

[English](README.md) · [Инструкции скилла](skills/cd/SKILL.md) · [Лицензия MIT](LICENSE)

CD проверяет работу, реализованную в текущем чате, разбивает её на подзадачи и передаёт каждую независимому ревьюеру. Если обнаружены дефекты, новый агент вносит точечные исправления, а другой новый ревьюер проверяет результат.

Цель — **9,5/10 для каждой подзадачи**, максимум **пять циклов исправлений на весь запуск**. Для принятия результата также нужны успешные проверки, актуальный снимок файлов и отсутствие незакрытых существенных дефектов. Оценка выражает суждение ревьюера, а не гарантирует отсутствие ошибок.

## Установка с GitHub

Отправьте в Codex:

```text
$skill-installer Установи скилл из https://github.com/GeorgVahi/CD/tree/main/skills/cd
```

Устанавливать нужно папку `skills/cd` целиком, включая инструкции, справочные материалы, схему отчёта и CLI-помощник. Корень репозитория не является папкой скилла. Если после установки CD не появился, перезапустите Codex. Установку из сторонних репозиториев поддерживает встроенный установщик: [официальная документация](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use).

Для установки фиксированной версии замените `main` в ссылке на опубликованный тег или SHA коммита.

### Ручная установка

Клонируйте репозиторий и скопируйте `skills/cd` в личный каталог скиллов. Команды используют [документированный путь локальных скиллов](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills) и останавливаются, если CD уже есть в этом каталоге.

**macOS / Linux (Bash):**

```bash
(
  set -eu
  git clone https://github.com/GeorgVahi/CD.git
  destination="$HOME/.agents/skills/cd"
  if [ -e "$destination" ] || [ -L "$destination" ]; then
    echo "CD already exists at $destination; preserve local edits before updating." >&2
    exit 1
  fi
  mkdir -p "$HOME/.agents/skills"
  cp -R CD/skills/cd "$destination"
)
```

**Windows (PowerShell):**

```powershell
git clone https://github.com/GeorgVahi/CD.git
if ($LASTEXITCODE -ne 0) { throw 'Clone failed.' }
$skillParent = Join-Path $HOME '.agents/skills'
$destination = Join-Path $skillParent 'cd'
if (Test-Path -LiteralPath $destination) {
    throw "CD already exists at $destination; preserve local edits before updating."
}
New-Item -ItemType Directory -Path $skillParent -Force | Out-Null
Copy-Item -LiteralPath './CD/skills/cd' -Destination $destination -Recurse
```

Для установки в общий проект скопируйте папку в `<project>/.agents/skills/cd`. Существующая установка Codex или встроенный установщик могут использовать `$CODEX_HOME/skills` (обычно `~/.codex/skills`); сохраняйте путь, которым управляет ваша установка. Не устанавливайте несколько копий с именем `cd` в каталогах обнаружения скиллов.

## Использование

Запустите CD в чате, где выполнялась реализация:

```text
$cd
```

При необходимости ограничьте область:

```text
$cd Проверь и исправь только изменения авторизации, реализованные в этом чате.
```

Для ревью без правок:

```text
$cd Только ревью. Не изменяй файлы, не делай commit и push.
```

CD запускается **только явно**: автоматическое подключение отключено в метаданных. Установка не регистрирует отдельную команду `/cd`.

## Как проходит работа

1. Координатор определяет изменения текущего чата, включая уже закоммиченные, и фиксирует состояние репозитория.
2. Один агент без права редактирования выделяет подзадачи, критерии приёмки и базу сравнения.
3. Каждую подзадачу проверяет новый независимый ревьюер. Он не получает прошлые оценки и вердикты.
4. Для незакрытых подзадач выполняются точечные исправления и новое независимое ревью. Пять циклов — общий бюджет всего запуска.
5. Координатор сообщает оценки, исправления, фактические проверки, блокеры и результат публикации. Работа завершается после принятия всех подзадач или когда разрешённых выполнимых действий больше нет.

В режиме без правок CD останавливается после первичного ревью. Если в чате нет реализованной работы, он сообщает об этом, не превращая запуск в аудит всего репозитория.

| Критерий | Максимум |
| --- | ---: |
| Корректность и выполнение требований | 4,0 |
| Устойчивость и безопасность | 2,0 |
| Интеграция и риск регрессий | 2,0 |
| Сопровождаемость | 1,0 |
| Проверка результата | 1,0 |

[Контракт ревью](skills/cd/references/review-contract.md) задаёт ограничения оценки по серьёзности дефектов и необходимые доказательства. Незакрытые P0–P2, недоступная обязательная проверка, устаревший снимок файлов или существенная неопределённость не позволяют принять результат даже при достаточной числовой оценке.

## Требования и ограничения

- Среда Codex с доступом к рабочим файлам и возможностью создавать субагентов с новым контекстом либо запускать совместимый установленный Codex CLI.
- Для резервного запуска через CLI: **Python 3.11+**, авторизованный Codex CLI и поддержка `codex exec` с `--json`, `--ephemeral`, `--sandbox`, `--output-schema`, `--output-last-message` и передачей задания через stdin. Python-помощник использует только стандартную библиотеку.
- Git для проверки Git-репозиториев и инструменты валидации самого проверяемого проекта.
- Уже существующий игнорируемый каталог внутри Git-проекта для контрольных точек. CD не меняет `.gitignore` проекта только ради запуска ревью.

CD использует встроенных субагентов, если их жизненный цикл позволяет создавать новые контексты. Если завершённые агенты продолжают занимать слоты и их нельзя закрыть, он переходит к отдельным новым CLI-заданиям. Формат запросов, восстановление состояния и команда помощника описаны в [runtime-recovery.md](skills/cd/references/runtime-recovery.md).

Вызов CD разрешает локальные исправления в пределах задачи, правил проекта и действующих полномочий. Скилл сохраняет чужие изменения, по умолчанию допускает одного пишущего агента и сохраняет счётчик циклов при восстановлении. Он не даёт новых разрешений на commit/push, не меняет выбранную модель, не устанавливает и не обновляет инструменты, не обходит лимиты аккаунта. В режиме только ревью нет staging, commit и push.

Задания агентов расходуют обычные лимиты Codex. Пять циклов — предел работы: запуск может завершиться ниже целевой оценки с честным отчётом об оставшихся дефектах или блокерах. Пакет документирован для Codex; другим агентным средам нужны эквивалентные механизмы исполнения и разрешений.

## Обновление и удаление

Установленная копия автоматически не обновляется при изменениях на GitHub. Сохраните локальные правки, обновите отдельный клон через `git pull --ff-only` и замените только установленную папку `cd` новой версией `skills/cd`. Встроенный установщик отказывается перезаписывать существующий каталог и не является механизмом обновления.

Для удаления уберите только установленную папку `cd`. Сохраняйте родительский каталог скиллов и конфигурацию Codex.

## Структура и проверки

```text
skills/cd/
├── SKILL.md                       Процесс работы и критерии принятия
├── LICENSE                        Лицензия для установки отдельной папки
├── agents/openai.yaml             Метаданные и запрет автозапуска
├── references/review-contract.md  Оценки и контракты агентов
├── references/runtime-recovery.md Выбор исполнителя и восстановление
├── scripts/run_agent.py           Одно CLI-задание с новым контекстом
├── scripts/agent-report.schema.json
└── tests/test_run_agent.py         Регрессионные тесты исполнителя
```

Из корня репозитория:

```bash
python -B -m unittest discover -s skills/cd/tests -v
python -B skills/cd/scripts/run_agent.py --help
```

Тесты используют подставной CLI-процесс, не требуют авторизации и не расходуют лимиты модели. Они проверяют жизненный цикл заданий, снимки файлов, восстановление, лимит циклов и завершение процессов. Они не доказывают совместимость со всеми действующими моделями и средами Codex. Инструкция для участников и проверки перед выпуском находятся в [CONTRIBUTING.md](CONTRIBUTING.md).
